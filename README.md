# 交课表 CourseBlock

交课表——适用于上海交通大学的 Android 端课程表 app。

本项目起初为上海交通大学信息安全专业应用软件课程设计的课程作业，后投入实际使用。

支持的平台：
* 教学信息服务网（本科生教务系统）
* 研究生应用管理平台（研究生教务系统）
* 医学院智能教学系统（医学院本科教务系统）

功能：
* 极速启动清爽无广告
* ~~支持桌面小部件~~

### 学期课表

在设置选择学年和学期，返回首页即同步。课表按教务数据的星期和周次显示。
交课表使用官方校历计算当前周。学期未收录校历时，仍可浏览教务周次。

### 日历提醒

首页菜单「将剩余课程添加到日历」可在授权后，直接写入手机上的「交课表」日历，
并设置课前 15 分钟提醒。再次执行会更新交课表写入的未来日程。
