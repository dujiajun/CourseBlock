# 交课表 CourseBlock

交课表——适用于上海交通大学的 Android 端课程表 app。

本项目起初为上海交通大学信息安全专业应用软件课程设计的课程作业，后投入实际使用。

支持的平台：
* 教学信息服务网（本科生教务系统）
* 研究生应用管理平台（研究生教务系统）
* 医学院智能教学系统（医学院本科教务系统）

功能：
* 极速启动清爽无广告
* ~~支持桌面小部件~~

### 学期与日历

首页顶部和设置使用同一个学期选择器。默认跟随当前学期，假期会选最近的后续学期。
选择其他学期后会自动同步，也可以恢复自动选择。课表格子按教务数据的星期和周次
显示，开关「显示周末」独立控制周末两列。

首页菜单「将剩余课程添加到日历」可在授权后
批量写入手机上的「交课表」日历。默认提前 15 分钟提醒，可在设置的「日历」中调整，
再次添加时会更新未来日程和提醒。提醒声音由手机日历的通知设置控制。
设置的「日历」也能添加课程，或移除交课表添加的全部日程。

校历数据来自[交大教务处](https://jwc.sjtu.edu.cn/jxxl/lnxl.htm)和
[医学院教务处](https://www.shsmu.edu.cn/jwc/xsfw/xnxl.htm)，具体学期及统一调课安排见
`AcademicCalendar.kt`。课程临时调动以教务课表和任课教师的通知为准。
